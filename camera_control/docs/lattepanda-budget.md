# LattePanda 3 Delta 864：追加購入を抑える構成

現在の前提はLattePanda 3 Delta 864（8GB/64GB）とWindows 10です。
既存の基板・ToF設計は保留し、画像検出を先に検証します。
**下記の金額は購入価格や現在の相場を確認した値ではなく、比較・見積もりのための予算目標です。**
販売価格・在庫・送料・税・型番との一致は未確認で、発注表ではありません。

## 最初は1台で試す

1. LattePanda本体、8GB RAM、64GB eMMCをそのまま利用。増設機器を初期購入せず、eMMCの空き容量を確認します。
2. 本体に冷却ファンが付いていて正常なら流用。追加冷却器を先に買いません。
3. 手持ちのHDMIモニタ／テレビ、キーボード、マウスがあれば利用。有無は未確認です。
4. 条件を満たすUSBカメラを**まず1台**用意し、50cm以下の設置高さで片側の範囲と列車の写りを評価。
5. 画角・レンズ歪み・停止車両の検出・Windowsでの実動画fpsを確認してから同型の2台目を検討します。

既存の電源と固定材を使える場合、最初の追加予算目標はカメラ1台2,000〜4,000円＋簡易固定具500〜1,500円＝2,500〜5,500円です。
**この範囲で必要条件に合う製品が存在することや、購入できることは未確認です。**
安価でも必要な画角や動画モードが合わない製品は買いません。候補が見つからなければ予算か撮影分割を見直します。
録画は初期OFFとし、eMMC容量を追加ディスクで補う必要があるかを実測して判断します。

## カメラの購入条件

| 項目 | 最初に確認する条件 |
|---|---|
| 接続 | USB UVC、Windows 10対応。Camera Module 3等のCSIカメラではない |
| 数量 | 最終的に2台を想定。最初の評価は1台 |
| 動画 | 1920×1080・15fps以上を実際に取得できるMJPEGモード。1280×720でも初期処理試験可 |
| 画角 | 実際に使う16:9動画モードで水平約100〜105°以上、垂直約65〜70°以上を目安。対角値と混同しない |
| レンズ | M12交換可能な広角モジュール、または画角を確認できる広角UVCカメラ。焦点距離だけでは画角を確定しない |
| 調整 | フォーカス・露出・ホワイトバランス等を固定できるものを優先 |
| ケーブル | USB**データ**ケーブルを含むか確認。充電専用ケーブルは不可 |
| 導入前確認 | 異なるカメラ2台をWindowsから同時に開けるか、実fps・フレーム時刻・遅延を確認 |

1m×1mの線路、カメラ高さ最大50cm、最大4列車が対象です。
カメラの高さはレイアウト面からではなく、**レンズから車両屋根までの実距離**で画角計算します。
参考として水平102°／垂直67°、屋根まで45cmなら約1.11×0.60mという幾何計算となり、上下を2台で分担できます。
屋根まで40cmでは横幅約0.99mで余裕がなく、同じ構成を保証できません。レンズ歪みと動画モードの切取りも含め、実画像で四隅まで確認します。
2台の重複領域を約10〜15cmから調整し、各カメラの担当範囲を設定します。

USB 2.0カメラでもMJPEG圧縮で必要な動画モードを持つ製品は候補になります。
非圧縮1080p YUY2・15fpsだけで約62MB/s必要なため、USB 2.0で同条件を当然に取得できるとは扱いません。
USBポートの数が足りても、共有帯域、MJPEGの復号、CPU負荷のため2台同時のfpsは実測が必要です。
高価な4K・AIカメラ・グローバルシャッター・マイク・赤外線LEDは最初の必須条件にしません。

### 型番を未確定としている理由

低価格カメラの「広角120°／170°」表記は対角値だけのことがあり、この条件では購入判断に不足します。
今回必要な水平・垂直画角を確認できる低価格の具体型番は、まだ確定できていません。特定商品を採用済みとは扱いません。

## LattePandaの電源・接続で追加費用を避ける

本体の付属電源がある場合は、まず型番・定格を確認して利用します。
メーカー仕様は、Type-C PDで**12V・3Aまたは15V・3A**、本体入力は11〜15V・24W以上です。
JST PH2.0・4ピン入力は12V・2A以上が推奨ですが、カメラ等を増やす場合は必要電力に余裕を持たせます。
「USB-C」「27W」「45W」の表記だけでは、必要な12V/15VのPD出力に対応するとは限りません。
Raspberry Pi 5用という理由で電源を買わず、対応PDプロファイルを確認します。
本体用とポイント負荷用の12Vを安易に同じ配線へまとめません。

USB Type-Aは3口あり、Gen2 10Gbps×1、Gen1 5Gbps×2です。Type-Cのデータ通信はUSB 2.0です。
カメラ2台はまず本体のType-Aへ直接接続。ハブは初期購入しません。
キーボード／マウスは手持ちの共用レシーバ等を使える場合は流用し、ポート不足が実際に生じてから対応します。

## ポイント制御は第2段階

LattePanda内蔵ATmega32U4は内部USBでIntel側へ接続され、WindowsではLattePanda LeonardoというCOMポートになります。
画像処理→Python→**内蔵USBシリアル→内蔵MCU→I2C内蔵ドライバIC**という構成にします。追加のUSBシリアル／USB-I2C変換器・Pi・Picoは不要です。
COMポートの確認、MCUへの有限パルス指令、通信断時の停止、ウォッチドッグ・起動時の出力抑止を実装・検証してから負荷を接続します。

KATOポイントをGPIOやUSB端子から直接駆動することはできません。
ユーザー指定により、ドライバIC自体に通信機能を持つ**DRV8235（I2C内蔵）×4**を候補にします。
DRV8871のようなGPIO入力のみのICを、通信内蔵品の代わりとして採用しません。
12V負荷電源、ヒューズ、出力停止スイッチ、局所容量、配線が別途必要です。
DRV8235の端子・I2C制御モード・4台のアドレス設定・電流制限・放熱・回生対策を確認して回路を確定します。
DRV8235の通信入力は推奨0〜5.5Vで、内蔵Leonardoの5V系I2Cと適合する範囲です。共通5Vプルアップを初期案とし、電源順序とバス配線を確認します。外部VREFは別条件で推奨最大3.3Vのため、5Vへつなぎません。
ICのLCSC価格・在庫・実装費は未確認のため、この部分の金額は空欄です。周辺部品やPCB費も別途見積もりが必要です。
旧3.3V基板の流用も保留し、通信内蔵ドライバを含む構成で再検討します。

## 初期には買わない物

Raspberry Pi／Pico、CSIカメラと変換ブリッジ、AI HAT、増設SSD、USBシリアル変換器、USBハブ、追加モニタ一式。
ToFセンサ・アナログバッファ・追加PCBも現在のカメラ検証の必須品ではありません。
照明は手持ちを利用し、ぶれや照度むらが問題になったときに拡散照明を追加します。
