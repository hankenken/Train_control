# センサ入力バッファ基板 TC SENSOR BUFFER Rev A

**回路図と部品配置の草案。未配線・未検証、製造不可。**
100×100mm、2層、3.3V専用、8入力。架線柱の上ではなく制御基板の近くへ設置します。
小型一体モジュールPololu QTRX-HD-01Aを各A/B位置へ設置し、車両の改造は不要です。

## バッファを追加する理由

Pololu公式回路図にはアナログOUTの47kΩプルアップが示されています。
反射条件によって出力源インピーダンスが高くなり、MCP3008のサンプル保持容量の充電に影響する可能性があります。
そのためMCP6004T-I/SLを2個使った8個の電圧フォロワを挿入します。
入力+はセンサOUT、入力−は同じアンプの出力へ直結。増幅率は1です。

Microchip DS20001733Lを取得し、SOIC14の端子、1.8〜6V動作、RRIO、1MHzの仕様を確認しました。
3.3V動作、無負荷時の消費電流は典型100µA/アンプ、8個で典型0.8mA（基板の最大消費電流ではありません）。
入力オフセット・レール付近の出力余裕・入力源とケーブルの影響は校正・実測対象です。

出力は100Ωで分離し、ADC側ネットへ1nF対GNDを配置する初期案。フィードバックは抵抗より前へ戻します。
100Ω×1nFだけの時定数は0.1µs。実際にはケーブル容量とADCの取得時間を含めて評価します。
この回路は過電圧保護でも、完全なノイズ除去回路でもありません。
500kHz/チャンネル100回毎秒の読取り案は、センサ電圧を既知電圧と比較して誤差確認後に確定します。

## 接続

- J1：1=制御基板と共通の3.3V、2=GND。独立電源や5Vをつながない。
- J2〜J9：1=GND、2=3.3V、3=モジュールOUT。CH0〜7に対応。
- J10〜J17：1=GND、2=バッファ後の信号。制御基板J2〜J9の1番と3番へ対応接続。
- 制御基板の各センサ端子2番（電源）をこの出力へつながない。
- 全センサ電源を本基板で配電。制御基板のJP1後のセンサ用3.3Vを利用する場合は、総電流を確認してからJP1を接続。
- PololuのHD端子配置はこの直付けパッド番号とは異なります。番号同士ではなくGND/VCC/OUTの名前で接続。
- CTRLはモジュール内部のプルアップを利用し初期は未接続。感度は高さ・ADC校正で調整。発光調光制御は次段階。

QTRXは最大5mA×8=40mA。バッファ典型0.8mAのほか、制御基板のADC・ロジックの電流も加えて電源余裕を実測します。
Piの3.3V端子の利用可能電流が自動的に確定したわけではありません。
