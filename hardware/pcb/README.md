# TC IO Rev C — 100mm角・部品実装依頼の準備

**LCSC調達・JLCPCB実装向けに再設計した候補版です。カタログ確認がネットワーク制限でできておらず、実装注文にはまだ使用できません。**

最新の指定は「IC・抵抗・コンデンサ・VRを実装。コネクタ部品は不要」です。
基板は100×100mm、2層のままです。実装対象は表面実装部品50点、全て表面です。
コネクタは取り付けず、電線直結・測定用の穴を21グループ残します。
旧Rev Bは固定パルス・挿入部品、Rev Cは個別VR・表面実装の設計です。

## 回路と部品の変更

- 8センサ入力、4系統の進路制御、GPIOと配線端子の電気的な割当を維持。
- U1：MCP3008T-I/SL候補、SOIC16。
- U2/U3：CD74HC221M96候補、SOIC16。
- U4〜U6：SN74HC08DR候補、SOIC14。
- U7：MCP100T-300I/TT候補、SOT-23。端子順はメーカー資料照合待ち。
- 固定抵抗R1〜R26：0805。旧SIP抵抗ネットワークは廃止し、21本の個別プルダウンへ変更。
- C1〜C4：470nF・10%・50VのX7R MLCC、1206。旧フィルム品から変更し、DCバイアス・温度特性の確認が必要。
- C5〜C12：100nF・50VのX7R、0805。C13：10µF・25VのX7R、1206。全て無極性。
- VR1〜VR4：Bourns 3224W-1-104E候補、100kΩの表面実装多回転トリマ。工場実装対象。
- FM1〜FM3：実装位置認識用の基板マーク。購入部品ではない。

「候補」はLCSCで購入・在庫・実装対応を確認できたという意味ではありません。
BOM草案へユーザー提供のLCSCコードと根拠を記録しています。C1〜C4はユーザー指定によりC2167387を採用しました。
現在の部品別状況は[選定状況](pcba/catalog/current-status.md)を参照してください。
DRV8871完成モジュール、センサ、Pi、ポイント、負荷電源は基板外の機器です。

## 基板の仕様案

FR-4、2層、100.000×100.000mm、厚さ1.6mm、外層1oz。面付けなし。
M3用3.2mm穴が4個。外形基準の中心座標は（4,4）、（96,4）、（4,96）、（96,96）mm、中心間隔は92mmです。
実装は表面のみ。コネクタやヘッダは実装せず、配線用のスルーホールへ電線を直付けします。
JLCPCBの実装対応・部品選定を確認してから最終プレビューと見積もりを確認します。

## 電線直結用のパッド

J/JP/TPの番号は接続位置を表す記号です。コネクタ部品を購入・実装する指定ではありません。
1番は角パッドです。基板に取り付ける電線には引張り止めを設け、はんだ部へ力がかからないようにします。

| パッド | 接続 |
|---|---|
| J1 | Piの40端子番号に対応。必要な信号だけ配線。5V端子は本基板で未接続 |
| J2/J3、J4/J5 | 上側外側A/B、上側内側A/B |
| J6/J7、J8/J9 | 下側外側A/B、下側内側A/B |
| J2〜J9 | 1=GND、2=センサ3.3V、3=アナログOUT |
| J10/J11、J12/J13 | 上側外側/内側、下側外側/内側のDRV論理出力 |
| J10〜J13 | 1=GND、2=IN1、3=IN2。12Vやポイントの青白線をつながない |
| J14 | 1=GND、2=3.3V、3=SDA、4=SCL。将来用 |
| JP1 | センサ電源の開放パッド。電流予算を確認するまでは接続しない |
| TP1/TP2 | 1=CLR_N/POWER_GOOD、2=GND |
| TP3〜TP6 | 1=各系統Qパルス、2=GND |

JP1はヘッダを取り付けません。センサ消費電流とPiの3.3V余裕を確認した後に、必要なら短い電線で接続します。
全センサをPiの3.3Vで給電できることはまだ確定していません。
負荷電流は外部DRVの太いGND配線で電源へ戻し、本基板の細いロジック線を使わないでください。

## パルス幅の調整

VR1=上側外側（TP3）、VR2=上側内側（TP4）、VR3=下側外側（TP5）、VR4=下側内側（TP6）。
回路は `3.3V → 固定150kΩ → VR 0〜100kΩ → RCEXT`。CEXT〜RCEXT間は470nFです。
VRの2番摺動端子を3番と接続しています。摺動接点だけが開いた場合は全抵抗側へ戻る構成ですが、全故障に対する保護ではありません。
典型式 `t≈0.7RC` の目安は49.35〜82.25ms。センサ判定やLED切替間隔は変えません。
R1%、C10%、VR10%を仮定した受動部品だけの上側計算は94.64msですが、IC係数、MLCCの温度・DCバイアス特性を含みません。
**100ms以下を保証する回路ではありません。** 負荷未接続で最小・中間・最大位置と使用条件を実測し、必要に応じてR/Cを変更します。
工場実装だけではVRは校正されません。ARM解除中に調整し、単発パルスでまず約50msへ合わせてください。
現在のWebアプリに実機GPIOドライバはなく、基板だけ接続してもポイント制御は始まりません。

## 検査と残作業

CADのDRC/ERC、未接続、回路図と基板のネット一致、VR結線、部品数と実装除外を検証します。
検査結果はreports配下に保存します。CAD検査は部品の購入可否、メーカー仕様、実機正常動作を証明しません。
LCSC番号・在庫・JLCPCB実装対応、採用品の端子/外形、CPLのピン1と回転の照合が未完了です。

接続許可の追加案は環境設定に保存済みです。設定を確認・保存し、環境を公開してからLCSC等への接続を再確認します。
必要ドメインはpcba/README.mdに記録しています。値や認証情報をチャットへ送る必要はありません。

編集はKiCad 9。`build_design.py`は未配線の初期データを上書き生成する開発用です。
配線後は`verify_and_export.py`で検査・製造データ出力、`prepare_pcba_draft.py`でBOM/CPL草案、`export_documents.py`で日本語PDFを作成します。

## タイミング精度の指定変更

ユーザー指定により、C1〜C4をC1206C474K5RACTU（C2167387、470nF±10%）へ変更しました。
厳密な100ms上限精度は要求せず、既存150kΩ＋100kΩVRを維持して実測調整します。
