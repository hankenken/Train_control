# JLCPCB向け TC IO Rev B 試作基板

Rev Bは外形を**100×100mm**へ変更した版です。旧Rev A（170×120mm）と部品・回路接続・端子のピン順は同一ですが、配置、配線、取付穴の位置は変更しています。
新規発注にはファイル名が`TC_IO_REVB`のZIPを使用してください。以前ダウンロードした`TC_IO_REVA`のZIPは旧寸法です。

**基板のみ発注し、部品は手ではんだ付けするためのデータです。実機未検証の試作版で、量産・完成動作を保証する版ではありません。**

## この基板の範囲

Pi 4とは40ピンのリボンケーブルで接続する独立基板です。Piに重ねるHATではありません。

- MCP3008によるアナログセンサ入力8個。
- 4系統の方向要求・単発トリガ入力、ハードウェアのパルス時間制限。
- 3.3V電源監視とARMによる出力禁止。
- 別置きDRV8871モジュールへ接続する3.3Vロジック出力4組。
- 将来用I²C端子。信号灯・直曲表示LEDの駆動回路は今回含みません。

**DRV8871、ポイント用12V電源・保護回路、実物の反射センサは別途必要です。**
DRV8871を直接載せると放熱パッドの実装が必要になるため、今回は手はんだしやすい制御基板＋外部完成モジュールに分けました。
外部モジュールは汎用の論理端子へ配線するため、特定製品の基板寸法やヘッダ配置には依存しません。
ただしDRV8871モジュールの電流制限定数・入力適合・電源保護は資料照合後に確定します。

ZIPには表裏の銅箔・レジスト・シルク、外形、PTH/NPTHの穴あけデータを含みます。
取付穴はM3用3.2mmが4個、基板端から各4mmです。
穴中心は基板外形の左上を基準に（4,4）、（96,4）、（4,96）、（96,96）mmで、中心間隔は縦横92mmです。
基板プレビューで寸法、部品穴、4つの取付穴、文字の向き、2層認識を確認してください。
基板の購入に先立ち、採用する挿入部品の実寸法とピン配置をBOM・配置図と照合してください。
100mm角の基板です。適用される価格・枚数・送料はJLCPCBの見積もり画面で確認してください。

## 配線・組立

| 端子 | 接続先／ピン順 |
|---|---|
| J1 | Piの40ピンヘッダ。ピン1同士を合わせる。基板上の5Vピンは未接続 |
| J2 / J3 | 上側外側 A / B |
| J4 / J5 | 上側内側 A / B |
| J6 / J7 | 下側外側 A / B |
| J8 / J9 | 下側内側 A / B |
| J2〜J9共通 | **1=GND、2=センサ3.3V、3=アナログOUT**。市販センサの端子順とは限らない |
| JP1 | センサ電源許可。**初期状態はショートピンを付けない** |
| J10 / J11 | 上側外側／内側のDRV8871ロジック接続 |
| J12 / J13 | 下側外側／内側のDRV8871ロジック接続 |
| J10〜J13共通 | **1=GND、2=IN1、3=IN2**。ポイントの青白線や12Vをつながない |
| J14 | 将来用I²C。1=GND、2=3.3V、3=SDA、4=SCL |
| TP1 / TP2 | 1=CLR_N／POWER_GOOD、2=GND |
| TP3〜TP6 | 各チャンネルの1=Qパルス、2=GND |

外部DRV8871のOUT1/OUT2へ青・白線を接続し、VMへ保護回路を経た12Vを接続します。
ドライバの負荷GNDは12V電源へ十分な太さで直接戻し、ロジック接続の細線をコイル電流の戻り経路にしません。
この基板のロジックGNDと外部負荷電源GNDの共通接続は、[駆動回路設計](../turnout-driver.md)の方針で配線します。

必要な付属品（基板上のICとは別）：

- DIP16ソケット×3、DIP14ソケット×3（表のフットプリントはソケット外形を確保）。
- 40ピンIDCケーブル。誤挿入・裏表逆接を防止できるもの。通電前に導通を確認。
- JST XH 3極ヘッダ×12と、対応ハウジング・コンタクト。基板側B3B-XH-Aと適合するもの。
- JP1用2.54mmショートピン×1。消費電流を確認するまでは装着しない。
- M3ねじ・絶縁スペーサ。別置きケースに固定する。

BOMの抵抗ネットワークRN1〜RN3は**共通端子1番の8×10kΩ・9ピン型**です。独立抵抗型と取り違えないでください。
U2/U3は**SN74HC221N**、U4〜U6は**SN74HC08N**です。LS/HCT系列に置き換えません。
タイマーのC1〜C4はフィルム470nF・5%、リードピッチ7.5mm、基板で想定する最大本体約10.3×5mmです。
R1〜R4は150kΩ・1%。パルスは約50msの試算で、3.3V実測後に調整します。
U7はMCP100-300DI/TOを想定。RESET/VDD/VSSの並びを実部品の資料と照合します。
メーカー資料のネットワーク取得ができていないため、ICの端子対応はKiCad 9標準シンボルとも照合していますが、メーカー資料での独立確認は未完了です。

## 初回通電

1. ICをまだ挿さずに短絡と向き、3.3Vの到達先を確認。
2. ICを装着し、JP1は開放、ドライバとポイントは未接続で起動。
3. POWER_GOOD、CLR_N、QとIN1/IN2を測定。起動直後は出力しないことを確認。
4. テスト用のGPIO要求で両方向を検証し、トリガ固着でもパルスが終わることを確認。
5. オシロスコープでパルス幅を測定。最長100ms以下、初期目標約50msを満たすようRCを評価。
6. センサ1個を校正。全8個の消費電流とPiの3.3V電源余裕を確認してから全数接続を判断。
7. 外部ドライバはダミー負荷で先に試験し、その後ポイント1台を試験。

**現在のWebアプリはGPIOを操作しません。基板だけを接続しても実機制御は動作しません。**
GPIOドライバ、実機校正画面、位置確認と競合進路の連動は後工程です。
詳細な合格条件は[駆動回路の試験手順](../turnout-driver.md)を参照。

## 検証結果と限界

- KiCad 9.0.2のDRC：違反0、未接続0。
- ERC：違反0。
- 回路図から書き出したネットリストと基板パッドの接続が全件一致。
- 穴あけデータはmm単位、PTH/NPTHを分離。必要な製造レイヤの存在とZIP内容を確認。
- 配置プレビューを確認。SHA-256で対象ソースと製造ファイルを記録。
- Rev Bの外形線中心の寸法は100.000×100.000mm。Gerberジョブ情報の寸法も線幅を含む表示値ではなく、この製品外形寸法に合わせています。
- `reports/revision-comparison.json`に旧Rev Aとの比較を保存。部品表と231か所の端子接続は同一です。
- 外部ドライバ・実物センサ・コイル・パルスの実測、温度試験、メーカー資料の独立確認は未実施。
- ERCはプロジェクト内のピン単位シンボルに対する検査で、元の部品仕様や光学性能を証明しません。
- 製造データの形式・接続検査が通っていても、実機での正常動作を保証するものではありません。

## 編集・再出力

KiCad 9＋標準ライブラリを使用します。`source/TC_IO_REVB.kicad_pro`を開いて編集できます。
配線済み基板からの検査・出力は、pcbnewを使えるPythonで `verify_and_export.py` を実行します。
`build_design.py` は初期回路図と**未配線**の基板を生成する開発用スクリプトです。配線済みファイルを上書きするので、通常の再出力には使いません。
配線にはFreerouting 2.1.0を使用し、KiCadへ戻して余分な枝配線を除去し、最終DRCを再実行しました。
再配線した場合も最終DRC/ERC、回路図と基板のネット一致を確認してからGerberを再作成してください。

日本語PDFの再出力は、KiCadで元図面を出力した後に`python3 export_documents.py`で行います。
Pythonの`reportlab`、`pypdf`、`fonttools`を使用し、未取得時はGoogle Fontsの公式リポジトリからNoto Sans JPを取得します。日本語フォントはPDFへ埋め込みます。
