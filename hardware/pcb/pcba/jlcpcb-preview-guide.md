# JLCPCB見積もり・実装プレビュー確認

このセットは見積もりと部品・向きの確認用です。注文の確定・支払いはまだ行いません。
メーカー端子図との照合済みということと、JLCPCB実装モデルの回転確認済みということは別です。

## Windowsでの操作

1. `TC_IO_REVC_JLCPCB_QUOTE_PREVIEW_ONLY.zip`を保存。
2. ZIPを右クリックし「すべて展開」。外側のZIPをそのままガーバーとしてアップロードしない。
3. ChromeでJLCPCBを開き、PCBの見積もり画面で、展開した中の`TC_IO_REVC_JLCPCB_prototype.zip`をアップロード。
4. 基板外形100×100mm、2層、FR-4、厚さ1.6mm、外層銅箔1ozを確認。枚数は必要数へ設定（比較見積もりなら5枚を仮設定可）。色など他の項目で迷ったら画面を共有。
5. PCB Assemblyを有効にし、実装面はTop／上面を選択。両面実装は不要。サービス区分はVR等の対応条件に従って選ぶため、この資料だけで安価な区分に固定しない。
6. `BOM_PREVIEW_ONLY.csv`と`CPL_PREVIEW_ONLY.csv`をアップロード。BOMはComment / Designator / Footprint / LCSC Part #、CPLはDesignator / Mid X / Mid Y / Layer / Rotationの列を対応させる。
7. 部品照合画面で全10種類が選択され、1枚当たり合計50点であることを確認。欠品・未対応があれば自動代替を確定せず、その行が見える画面を共有。
8. 実装プレビューでICとVRの1番端子と向きを確認。`review/IC_VR_pin1_review.pdf`を参照。判断しにくい部分は拡大した画面を共有。

表示名や手順はサイトの更新で変わる場合があります。現在の画面の表示を優先します。

## 実装プレビューの見方

- 基板上に全50点が載り、基板外へ飛び出した部品や全体の位置ずれがないこと。
- U1〜U6の1番端子、U7の1/2/3番、VRの1/2/3番が基板パッドと対応すること。
- 非対称なVRとSOT23を「角度の数値が同じ」という理由だけで承認しない。
- 無極性コンデンサ・抵抗は電気的極性がないが、位置とサイズが合うこと。
- 現在のCPLはKiCad絶対座標とY反転を使用。負のY値を一律に正へ置き換えない。サイトが原点を変換した結果をプレビューで確認する。
- 全体がずれている場合は原点変換を検討する。部品ごとのずれなら吸着中心・モデルを照合する。

## 現状

C1〜C4はユーザー指定のC2167387を採用済み。タイミングは概略値として個別VRで調整し、厳密な100ms上限精度は要求しません。
実装対応・在庫・モデルの向き・吸着中心はJLCPCB画面での照合待ち。見積もり取得は発注完了ではありません。
基板は3.3V制御・ADC用で、DRV8871モジュール・12V保護・センサ・Pi・ポイントは別途必要です。
