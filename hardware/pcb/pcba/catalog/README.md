## コンデンサ代替の評価

J=±5%、K=±10%という型番上の差を前提とした再計算です。実際の商品仕様は資料で照合します。
150kΩ±1%＋100kΩVR±20%、470nF、時間係数0.7の仮定で、受動部品だけの最大値はJ品約93.79ms、K品約98.26msです。
K品は100msまでの計算上の余裕が約1.74msしかなく、IC係数等は含まれません。この条件で100ms上限を保証することはできません。
そのためK品への置換はまだ採用せず、J品の調達またはRC範囲の変更を資料照合後に判断します。
