## 発注前に必要なこと

1. 全50点のLCSC掲載・在庫・実装対応を確認し、メーカー型番、LCSCコード、調達方法を固定。
2. メーカー資料で値・パッケージ・端子順・推奨回路を照合。MLCCとVRのパルス幅を評価。
3. 必要な部品変更に合わせて回路・フットプリント・配線を更新し、ERC/DRCと接続一致を再検証。
4. ガーバー、ペースト、BOM、CPLの版・部品数・面を合わせ、JLCPCBの部品モデルで位置と回転を照合。
5. 最終プレビュー・見積もりを確認。現在の草案では発注しない。

DRV8871モジュール、Pi、センサ、ポイント、電源はこの基板の実装とは別です。

## WindowsのChromeを使う確認方法

クラウドからカタログを取得できない場合は、`catalog-review.html`を保存してChromeで開いてください。
10種類の候補についてLCSC/JLCPCBの検索リンクを開き、LCSCコード・在庫・実装対応・商品URLを入力できます。
検索URLで結果が出ない場合は、表示されているメーカー型番を各サイトの検索欄へコピーしてください。
「確認結果をCSVで保存」で出力したCSVと、商品ページから取得したデータシートを共有すると、候補の照合と再設計を進められます。
この表は手動確認の記録であり、自動的に調達確認済みにはしません。ページを閉じる前にCSVを保存してください。

回路側の確認項目と試験条件は `electrical-review.md` に記載しています。
