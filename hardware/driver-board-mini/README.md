# ポイント駆動基板 TC DRIVE Rev B 小型配置案

**60×45mm（暫定）・未配線・製造不可。100×100mmのRev Aと既存制御基板を変更せず、別リビジョンとして作成。**

基板面積は10,000→2,700mm²（73%減）。12V、DRV8871×4、表面実装35点、コネクタなし、制御3線×4組とポイント2線×4組、電源2線の9直付け位置を維持しています。
電気的なネット・部品値はRev Aと同一であることを検査しました。4回路入りの集約基板として詰めた配置案であり、実装・配線・熱設計後も維持できる最小寸法を保証するものではありません。

## 小型化の内容

- 4つのDRV8871を2×2配置。各チャンネルの入力・電流制限・デカップリング・100µFを近接配置。
- 大容量470µFと電源保護候補は上側へ集約。電解コンデンサを削除して面積だけ小さくする変更はしていません。
- 直付け穴は電源／コイル用が直径1.3mm・ランド3mm、制御用が直径1.0mm・ランド2mm。電線に引張り止めを設ける前提。
- 取付穴は**4個のM2用2.2mm穴**へ変更。外形から各3mm、中心間54×39mm。Rev AのM3とは互換ではありません。
- 三つの1mmフィデューシャルを追加。大半の部品記号をF.Fabへ移し、上面シルクはICと接続位置を優先。
- DDAのメーカー推奨ランド／マスク形状を維持し、プロジェクト専用フットプリントの熱逃がし穴を0.3mm、銅ランド0.6mmへ変更。各IC8穴でGNDに接続。

## 回路条件

53.6kΩ±1%による公称電流制限は約1.194A。メーカーVILIM範囲と抵抗誤差の計算では約1.090〜1.300A。
制御入力はGND/IN1/IN2、ポイントはOUT1=青／OUT2=白。青白は極性反転するため常設＋／−ではありません。
パルス幅とVR、B検知後だけの転換許可はTC IO側が担当。この基板だけで連続通電を防ぐ設計ではありません。
外部ヒューズ・保持型停止スイッチを通した12Vだけを使用し、1系統ずつ駆動します。
SS34、SMBJ18A、470µF/35V、100µF/35V等はまだメーカー型番・調達未確定の候補。保護協調、回生エネルギー、温度特性は未検証です。

## 検査結果

- ERC：0件。
- 回路図と基板：120端子割当が一致。
- 部品値・ネット・実装対象：Rev Aから変更なし。
- 配置段階のDRC：**0件**。銅箔間隔規則0.20mm。
- 異なるネットのパッド外接矩形による距離の最小値：0.20mm（保守的な下限計算）。配線幅や許容電流の評価ではありません。
- **未接続89件、配線0本。** 熱・電流・回生・ノイズを評価する銅配線とGND面は未実装です。

0.2mm間隔のDDA信号端子付近と、電源・負荷の太い配線、裏面GND面、熱逃がしを両立させることが次工程です。
小型化したことで放熱余裕が減る可能性があるため、配線時に面積や寸法の再調整が必要になる場合があります。
必要な露出パッドのはんだ付け、熱逃がし穴のマスク／ペースト／ビア充填の実装条件もJLCPCBと照合します。
