# ToFセンサ選定 — 架線柱、屋根まで約10mm

**メーカー資料に基づく選定メモ。回路基板・部品調達・10mmでの実機検出は未確定です。**
ユーザー指定によりToF方式を優先し、アナログ反射方式とMCP6004バッファは採用対象から外します。

**1mmまで測れるという記載は、1mmの精度を保証する意味ではありません。**
上表の精度は少なくとも90%の測定値が範囲内という品質指標であり、全測定の絶対上限保証ではありません。
1〜100mm、屋外曇天の同条件では白±8mm、灰±7mm。黒い屋根、鏡面、パンタグラフ、照明での実機試験は別です。
10mmの屋根検知は「1mm単位の正確な距離」ではなく、「車体なしの背景」との差・測定有効フラグ・ヒステリシスで評価します。

### 電源の注意点

3.3VはAVDDとI/O双方の動作範囲内なので、必ず2.8Vしか使えない部品ではありません。
ただし3.3Vの許容差・負荷過渡・電線降下を含めて2.6〜3.5Vへ収めます。5Vや12Vは直結しません。
8個を同時測距すると、上記条件で最大平均192mA、ピーク重なりの仮定で320mAです。
旧アナログモジュールの合計40mAという電源計算は流用しません。専用の安定化3.3V電源と配電・局所容量を設計し、Piのセンサ用3.3V端子だけに全8台を載せる構成は避けます。上流ロジック用電源とセンサ電源の分離・共通GND・電源断時の逆給電も確認します。

### 1モジュールで完結する小型基板の構成案

部品VL53L4CD自身が発光と受光を一体化。架線柱上にはこの部品と必要な受動部品を載せた1枚の小型基板だけを配置します。
資料5ページの推奨例は100nFと4.7µFを電源ピンの直近へ配置。XSHUTは10kΩで同じ電源へプルアップし、浮かせません。
GPIO1はオープンドレインのデータ準備割込み。使用しない場合は未接続にできますが、資料はハードウェア割込みを推奨しています。
最小配線の案は3.3V/GND/SDA/SCLの4線。GPIO1未使用時は公式ドライバでready/statusを確認し、タイムアウトを実装します。
XSHUTをホストから操作する場合は追加配線が必要です。4線構成では個別のハードリセット・停止手段を別途検討します。
I2Cプルアップ値は配線容量・電圧・速度を見て決め、モジュールと母基板の並列接続後の実効値を確認します。
小型基板は約10×10mmを初期目標とし、素子・局所容量・4本の直付け位置・光学窓の確保を配置で確認してから確定します。素子の4.4×2.4mmという寸法を、完成モジュール寸法として扱いません。LCSC番号は未確認です。

## 8台の同一アドレスへの対応

TI TCA9548Aを第一候補とする8チャネルI2Cスイッチで、センサ1台ずつを各下流バスへ分離します。
公式資料：https://www.ti.com/lit/ds/symlink/tca9548a.pdf （SCPS207H、2024年9月）
電源1.65〜5.5V、上流・下流プルアップによるレベル変換、最大400kHz。VL53L4CDの1MHz能力をそのまま8台システムへ適用しません。
A0/A1/A2をGNDに固定すればスイッチの7bitアドレス0x70。センサ0x29とは異なります。
一度に1下流チャネルだけ有効にすれば、同アドレス同士が同じI2Cトランザクションへ応答することを防げます。
起動時・RESET時は全チャネル非選択。RESET端子を浮かせず、バス障害時の復帰手段を設けます。
スイッチのRESETはセンサ自身のRESETと同義ではありません。

I2Cのチャネルを切り替えても、センサの発光・測距が停止するわけではありません。
同時測距では光学干渉を確認。順番に測距する方式なら測定時間が台数分に増えます。
33ms×8台を単純に直列化すると約264ms/巡回（通信等を除く）で、各センサ100Hzにはなりません。
連続測距＋順次読出し、A/Bの優先スケジュール、遮光と設置距離を組み合わせ、実際の速度で評価します。
長い模型配線でのI2Cの立上り時間・容量・ノイズは未検証。最初は100kHzを候補とし、配線長で必要ならバス拡張方式を再検討します。

## 比較候補：VL6180X

公式資料：https://www.st.com/resource/en/datasheet/vl6180x.pdf （DocID026171 Rev7）
0〜100mmという近距離範囲、光学一体モジュールですが、寸法4.8×2.8×1.0mmでVL53L4CDより大きい。
AVDDは2.6〜3.0V（本文8ページの機能範囲）なので、Piの3.3V電源を素子へ直結できません。
現時点では寸法・3.3Vとの適合・近距離線形性の記載からVL53L4CDを優先します。

## 10mm条件での受入試験案

1. 1台で車体なしの距離とstatus、黒・白・銀の屋根を5/10/15mmで記録。
2. パンタグラフを避けた設置と、屋根の有無で安定した差が得られることを確認。
3. 照明・外光・隣接センサの同時発光で無効測定と誤検知を記録。
4. 手動の停止・発車・通過でA/Bの検知遅れと時刻差誤差を評価。
5. 初期化失敗・測距timeout・無効statusを「車体なし」と同一扱いにしない。
6. 全8台と電源・配線の条件を確認してから量産基板を確定。

メーカー資料の保存・SHA-256は`selection.json`を参照。資料確認だけで全屋根・全照明での検出は保証しません。

## 小型基板への反映

ToF対応制御基板の配置案は50×40mm（46実装部品）。不要なADCとSPI4信号を削除し、I2Cホストを残しています。
駆動基板の配置案は60×45mm。どちらも配線前であり、必要な放熱・電線・光学領域を削って寸法を確定する方針ではありません。
注文型番の第一候補はDS本文32ページのVL53L4CDV0DH/1（光学面ライナー付き）。ライナーなしV9との取扱い差も製造工程で確認します。LCSCコード・在庫・実装対応は未確認です。
小型光学基板（約10×10mm目標）と8台の切替・専用電源基板はまだCAD配置を作成していません。
