## 電源と駆動

試作は**12V**、同時駆動は1系統です。ユーザー提示の20.5Ωなら12V/20.5Ω≒0.59Aで、電源・配線・FETの損失でさらに下がります。約0.8〜1.0Aという別条件の値が12Vでも流れると仮定しません。切替に必要な電圧・実測電流・幅を確認します。

各DRV8235のIPROPI抵抗は1.69kΩ±1%、内部3V基準を選択。公称制限値は約1.183Aです。基準±4%、電流鏡±5%、抵抗±1%を組合せた試算は約1.071〜1.309Aで、その他条件を含む保証値ではありません。これは上限で、コイルに1.18Aを強制する回路ではありません。

12V入力は外部ヒューズと保持型停止スイッチを経由します。SS34候補で逆接を阻止、VM側に470µF/35VとSMBJ18A候補、各IC直近に100nFを置きます。ソレノイドのインダクタンス・回生エネルギーは未測定のため、TVS・容量・電源の組合せは未確定です。極性反転する負荷の両端に通常の一方向フライバックダイオードを並列接続しません。

DRV8235の露出パッド17はGNDへはんだ付けし、GND面とサーマルビアへ接続します。3.7AピークというIC仕様だけで基板の許容電流や温度を保証しません。TI RTE0016CはEP1.68×1.68mm。名前にRTEが含まれていても、EP0.8mm等の別パッケージのフットプリントを流用しません。

## 独立した時間制限

通常の方向・ON/OFFはすべてI²Cです。追加のGPIOは故障時の禁止に使います。

```text
D5立上り → CD74HC221 非再トリガ単発Q ──┐
D4 SLEEP_REQUEST ─────────────────────┼ AND → 全4個nSLEEP
5V電源監視 POWER_GOOD ────────────────┘
単発Q → D6（戻り監視）、全nFAULT → D7
```

U5=CD74HC221M96、R5=620kΩ、C10=470nFで、4.5V時の式0.7RCは約204msです。**これは公称試算です。部品・電源・温度を含む上限保証ではありません。** 初期の実測受入目標は160〜260msとし、満たさない場合は値を変更します。通常の20〜100msパルスはMCUが管理し、204ms単発はMCU停止時の別経路です。100ms以内をハードウェアで保証する回路ではありません。

単発動作中の追加トリガでは延長しないHC221を選びます。D4がHIGHで固着しても単発QがLOWへ戻れば禁止します。Qが戻るまでファームウェアは新しいトリガを出しません。ARM時も設定確認用の単発を使うため、直後のPULSEは残った単発の終了を待つことがあります。

MCP100の4.5Vグレードを5V監視用候補とし、POWER_GOODでU5リセットと最終ANDを禁止します。前の3.0Vグレードと区別します。電源立上り・低下時の動作、未使用HC入力の固定、nSLEEPプルダウンと出力LOW電圧を実測します。

nSLEEP中に内部デジタルロジックがリセットされる記述があるため、毎回ウェイク後に設定を再確認します。異常停止で最後のEN_OUT解除を確認できなかった場合、MCUだけの再起動で再開しません。**MCU起動後にVMが十分下がり、その後12Vが復帰したことを観測**するまでARMを拒否します。NPORやスリープだけで全レジスタの安全な初期状態を証明したとは扱いません。

スリープ中も逆起電力でOVPが下側FETをONにする場合があります。「電源からの駆動を禁止する」と「負荷電流が瞬時にゼロになる」は同じではありません。

## LattePandaとの配線

| 論理端子 | この基板のネット | 用途 |
|---|---|---|
| 5V / GND | +5V_LOGIC / GND | 内蔵MCUと共通の5V、12Vを接続しない |
| D2 / D3 | SDA / SCL | 100kHz、共有4.7kΩプルアップ各1本 |
| D4 | SLEEP_REQ_D4 | 外部10kΩでLOW、許可要求 |
| D5 | TRIG_D5 | 外部10kΩでLOW、単発の立上り入力 |
| D6 | PERMIT_D6 | 単発Qの読戻し、外部10kΩでLOW |
| D7 | FAULT_N_D7 | 4個のオープンドレインを共通化、10kΩで5Vへ |
| A0 | VM_ADC_A0 | VM電源の入れ直し確認。ポイント位置の検出ではない |

D2等はArduino Leonardo論理番号です。実際のLattePandaの引出し位置はメーカー図と現物を照合します。USBからWindowsがI²Cを直接操作するものではありません。

VM_ADCは100kΩ/10kΩの分圧、BSS138候補のアナログ通過回路、A0側1MΩ・10nFです。5V稼働時の概算分圧比は約11.1、12VでA0は約1.08V。**Q1のソースをA0、ドレインを分圧側**とし、5Vが失われたときのボディダイオードによるVM→A0給電を防ぐ向きにします。具体メーカーのQ1仕様とOFF漏れ・実電源順序は未検証です。5VをOFFにしてもVMをONにした試験でA0・5Vへの回り込みを確認します。

ファームウェアの初期閾値はADC≤5を100ms、続いてADC≥150を100ms。5V基準・分圧誤差を含めてVM換算およそ≤0.27Vと≥8.1Vです。実測校正が必要で、ADCの切断・短絡まで診断できる安全認証用の監視回路ではありません。

VMには2.2kΩ/0.5Wの放電抵抗R18を追加します。470µFとの時定数は約1.03秒、理想計算では12Vから0.27Vまで約3.9秒です。入れ直し時は固定秒数を根拠にせず、実際にADCの低下を確認します。

4アドレスは0x30 / 0x32 / 0x36 / 0x38（7ビット）。各系統の青白線とP/N・直/曲の対応は未確定です。

## 組立・試験順序

1. 先に配置・配線、銅箔幅、サーマルビア、部品の具体MPNと実装可否を確定する。現データは基板発注に使用しない。
2. 製作後は無通電で極性・ピン1・短絡・VMと5Vの分離を確認する。WQFNの露出パッド実装も検査する。
3. ポイントを接続せず、電流制限した12V電源と5Vで電源順序を試験する。5V未給電・MCU未接続・リセット中のnSLEEPを測定する。
4. オシロスコープでD5、単発Q、D4、nSLEEPを測定し、繰返しトリガ・D4 HIGH固着でも単発が延長されないことを確認する。
5. 20〜22Ωの適切な電力定格の抵抗負荷から、P/N、20/50/100ms、全4アドレス、同時要求の拒否を測定する。抵抗負荷でソレノイドの回生試験を代替しない。
6. USB断、HB断、SDA/SCL固着、nFAULT、VM低下、MCU停止、応答欠落で駆動禁止と再開条件を検査する。測定結果を記録する。
7. ポイント1個を接続し、低頻度で必要最小のパルス幅を調整する。機械位置・電流・回生・温度を確認してから4系統へ増やす。

現時点のERC=0はネット接続の機械的なルール検査です。タイマ上限、実装、放熱、実際の切替成功を証明しません。カメラアプリの出力は無効のままです。
