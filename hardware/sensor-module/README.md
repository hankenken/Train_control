# 架線柱上の一体型センサと取付案

## 選定候補の具体化

Pololu **QTRX-HD-01A（製品4401）**を第一候補とします。
公式仕様：https://www.pololu.com/product/4401/specs
公式製品説明：https://www.pololu.com/product/4401

| 項目 | メーカー掲載値 |
|---|---|
| 方式 | 発光・受光一体の反射式、アナログ出力 |
| 最適距離 | 10mm |
| 最大範囲 | 30mm（特定条件の掲載値。全車体での検出保証ではない） |
| 電源 | 2.9〜5.5V。今回はADCと共通の3.3V |
| 最大電流 | 5mA/個、8個で40mA |
| 寸法 | 製品仕様5.0×20.0×4.4mm。寸法図の幅は5.1mmで表記され、基板公差もあるため干渉を避ける |
| CTRL | 内部プルアップで初期全点灯。未接続で開始可能 |

QTR-HD-01A（4201）は最適5mm・最大32mA、QTRXL-HD-01A（4601）は最適20mm・最大32mA。
今回の10mm設計には、低電流QTRXを優先。距離をmmとして出力するToFセンサではなく反射量なので、屋根色と背景の校正が必要です。
Pololu完成モジュールを使うため、このモジュール自体はJLCPCB製作対象ではありません。架線柱上の自作基板を増やさず、配線3本で完結させます。
JLCPCB/LCSCのみで調達する自作光学基板を希望する場合は、光学素子の選定と10mm評価が別途必要です。

## 配線の意味

モジュールのVCC→3.3V、GND→共通GND、OUT→バッファ基板のセンサ入力。
HDタイプはCTRL/VCC側とOUT/GND側の並びです。MDタイプと並びが異なるため、モジュールの印刷・公式回路図と照合して直付けします。
電線に引張り止めを設けます。CTRLは初期未接続で、線路電源や12Vへ接続しません。

## 架線柱の取付構成

- センサを下向きとし、検出面から屋根まで10mmを標準にする。
- 検出面を基準として5〜25mmへ調整する上下スライド（20mmストローク）。最大範囲は全域の実機動作保証ではない。
- キャリア内幅は仮6mm、長さ24mmを確保。基板端部だけを保持し、下面のレンズ・素子を押さえない。
- 光学面を基準に高さを調整し、基板全厚4.4mmを光学距離として扱わない。
- パンタグラフと架線の通り道を避け、屋根の連続部分へ横位置を調整。
- 遮光フードは視野を遮らない形とし、向かい合うセンサの赤外線干渉も評価。
- キャリアは樹脂製の着脱式を想定。M2の柱側スライドを使う案。架線柱寸法未受領のため穴径・クランプ形状は製作用に確定しない。

## 実機で確認すること

まず1個で黒・白・銀の屋根、停止中、照明ON/OFF、5/10/15mmでADC値を記録します。
車体なし／ありの差が校正条件を満たすことを確認し、A/Bセンサが列車を1回だけ検知できるよう調整します。
「停止位置の判定」や「Bでの選択」は既存ソフトウェアの担当。センサの前で自動停止・自動発車はしません。
全8個の動作、電源電流、ノイズ・太陽光・相互干渉は未確認。
公式の回路図・寸法図は`reference/`に保存しています。
