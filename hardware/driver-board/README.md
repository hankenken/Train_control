# ポイント駆動基板 TC DRIVE Rev A

**回路図と部品配置の草案。未配線・未実機検証。発注用ガーバーではありません。**
100×100mm、2層、4系統、12V専用。JLCPCB向け表面実装を想定し、コネクタを載せず電線を直付けします。
制御基板TC IO Rev CのJ10〜J13へ接続し、DRV8871の完成モジュール4個をこの基板で置き換える計画です。

## 確認済みの回路仕様

メーカーTI SLVSCY9Bを今回取得し、本文3/5/8/9/15ページの端子・入力・電流式・レイアウトを参照。
DRV8871DDARはIN1=3番、IN2=2番、VM=5番、OUT1=6番、OUT2=8番、GND=1番、PGND=7番、露出パッド=GND。
INのHIGHしきい値1.5V以上、LOW0.5V以下。制御基板の3.3Vロジックを受ける構成です。
VMの定格動作範囲は6.5〜45Vですが、この基板は12V限定で設計します。

| IN1 | IN2 | 出力 |
|---:|---:|---|
| 0 | 0 | 両出力High-Z、約1ms後スリープ |
| 1 | 0 | OUT1→OUT2。青→白の極性 |
| 0 | 1 | OUT2→OUT1。白→青の極性 |
| 1 | 1 | 両出力LOWのブレーキ。通常の要求では使用しない |

各INへ100Ω直列と10kΩプルダウンを追加。DRV8871自身にも内部プルダウンがあります。
進路確定前に駆動しない動作、ワンショットと各VRは既存制御基板の担当です。この基板だけでは通電時間を制限しません。
4系統を同時に通電しない前提。全系統の入力LOWを保持してから12Vを投入します。

## 電流制限

各ILIMへ53.6kΩ±1%を接続。資料の式Itrip=VILIM/RILIMに基づき、公称1.194A。
VILIM=59〜69kVと抵抗誤差を含む計算範囲は約1.090〜1.300Aです。
実コイルの12V・20.5Ωというユーザー情報では抵抗だけの定常計算は約0.59Aで、この制限に達しない可能性があります。
1.2Aを必ず流す回路ではなく、電流が増えたときの制限です。実電流・転換成功の確認が必要です。

## 電源・保護

外部の安定化12V電源→外部ヒューズ（初期候補2A）→保持型出力停止スイッチ→J1。
J1からD1の直列ショットキーを介してVMへ。逆接時の遮断を意図しますが、SS34の具体メーカー・損失・温度特性は照合待ち。
VMには18V系TVS候補、470µF/35Vの共通バルク、各系統100µF/35V＋100nF/50Vを配置する案です。
TVS型番SMBJ18Aは候補。実際のクランプ電圧、エネルギー、ヒューズ協調と配線寄生を確認して固定します。
D1により電源側へ回生が戻りにくいため、局所バルクとクランプの評価は特に必要です。
コイルのインダクタンスが未測定なので、これらの定数で回生吸収が完了するとは判断していません。
コイル両端へ単独ダイオードは付けません（極性反転と両立しないため）。
12V入力を切ってもバルク容量の電荷で短時間通電し得ます。停止時は制御基板ARMも解除し、蓄積電荷と出力波形を試験します。

## 接続（番号は部品でなく直付け位置）

| 接続位置 | 内容 |
|---|---|
| J1 | 1=12V入力、2=GND。ヒューズ・停止スイッチの後 |
| J2/J3/J4/J5 | 1=GND、2=IN1、3=IN2。順にUP_OUT/UP_IN/LOW_OUT/LOW_IN |
| J6/J7/J8/J9 | 1=青、2=白。対応するポイント2線 |

青白と「直／曲」の対応は現物でチャンネルごとに記録。PiのGNDは負荷電流の戻り経路にしません。
制御・センサ用3.3Vと12Vを接続しないでください。

## 配置・配線の次工程

現在は35点の実装部品と9グループの直付けパッドを仮配置。回路用PWR_FLAGは物理部品ではありません。
IC露出パッド9はGNDに接続し、サーマルビアで裏面銅箔へ放熱します。TI DDA0008Bの推奨マスク寸法に対応する候補フットプリントを選びました。
初期方針は負荷配線1.0mm以上、共通VM/GND幹線2.0mm以上＋銅箔面。長さ・温度上昇・ビア数を評価して決定します。
現時点では銅配線・GND面・熱設計が未実装。配置のDRCと配線・熱設計の合格を意味しません。
部品のLCSCコード、電解コンデンサの具体型番・寸法、TVS・ダイオードも未確定です。
