# センサバッファ小型版 Rev B — 45×32mm

**配線前の配置草案です。発注用データではありません。**
旧100×100mm版を保存し、別リビジョンとして小型化しました。面積1,440mm²、旧比85.6%削減。
MCP6004T-I/SL×2、100Ω×8、1nF×8、100nF×2、10µF×1の実装21点と各ネット接続を維持しています。

## 寸法の考え方

- SOIC14を2個と、手直ししやすい0805/1206を維持。JLCPCB実装部品の再選定を最小限にします。
- センサ8組の3線直付け位置を上下4組ずつに分け、配線の引き出しを確保。
- 従来の8組のGND/OUTと別電源パッドを、共通GND・3.3V・8信号の10線へ集約。
- 直付け穴径0.8mm、パッド1.6mm、ピッチ2.0mm、パッド間隔0.4mm。AWG26程度の信号線を目安とし、より線のはんだ上がり後の外径を現物で確認。
- 取付はM2用2.2mm穴4個。中心は(2.8,2.8)、(42.2,2.8)、(2.8,29.2)、(42.2,29.2)mm。
- 現段階では実用的な配置目標寸法であり、理論上の最小寸法を証明したものではありません。最終配線・GND面・信号評価で寸法の微調整が必要になる場合があります。

## 配線が旧Rev Aから変わります

J1とJ11〜J17の個別出力グループは廃止。出力・電源はJ10の2列×5段の直付けパッドへ統合します。
1番は角パッド。上から1/2、3/4、5/6、7/8、9/10という並びです。コネクタは実装しません。

| J10番号 | 信号 | 既存制御基板への接続 |
|---:|---|---|
| 1 | 3.3V | ADCと共通のセンサ用3.3V（JP1後等。総電流確認後） |
| 2 | GND | 共通GND |
| 3 | ADC0 | TC IO J2-3 |
| 4 | ADC1 | TC IO J3-3 |
| 5 | ADC2 | TC IO J4-3 |
| 6 | ADC3 | TC IO J5-3 |
| 7 | ADC4 | TC IO J6-3 |
| 8 | ADC5 | TC IO J7-3 |
| 9 | ADC6 | TC IO J8-3 |
| 10 | ADC7 | TC IO J9-3 |

J2〜J9は各センサ入力で、1=GND、2=3.3V、3=OUT。S0〜S7の印刷はセンサ番号です。
Pololuモジュールのピン配列と番号は同一ではありません。GND/VCC/OUTの信号名で対応させます。
この基板は3.3V専用です。12V・5Vや独立した別電源を接続しません。
10線集約でGNDは共通1本になります。電線の引張り止めを別途設け、コイル電流が流れるGND配線と共用しないでください。

## 確認結果

- 電気ルールERC：0件。
- 配置DRC：0件。既定の最小クリアランス0.2mmで配置を確認。
- 21実装部品の値・フットプリント・端子ネットは旧Rev Aと一致。
- 回路図と基板の100端子割当が一致。
- 銅配線0本、未接続74件。配線・GND面・ADCの信号品質評価は未完了。

既存100mm制御基板や、JLCPCB画面での回転補正には変更を加えていません。
LCSCコード・吸着中心・JLCPCB実装モデルの向きは未確定です。製造用ガーバーは出力していません。
