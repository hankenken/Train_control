# TC IO Rev D MINI — ToF対応の小型制御基板案

**50×40mm（配線前の暫定寸法）・未配線・発注不可。**
100×100mm Rev Cを保存し、ユーザーの小型化とToF指定に合わせた別リビジョンです。
面積は10,000→2,000mm²（80%減）。コネクタ部品なし、実装46点。
全体の物理的最小寸法を証明したものではなく、2層配線・実装条件の確認で寸法が変わる可能性があります。

## 電気回路の変更

- ポイント4系統のワンショット・個別VR・方向ゲート・電源監視を維持。
- ユーザー指定のC2167387（470nF±10%）と個別VRでの概略時間調整を維持。
- ToFはI2Cで接続するため、MCP3008（U1）、ADC用R5、C5、C12を削除。
- SPIのMOSI/MISO/SCLK/CS配線と、アナログセンサ端子・JP1を削除。
- Pi GPIO2/3のI2Cは維持。VL53L4CD×8は別のI2C切替・電源基板経由で接続する計画。
- ToF切替・電源基板はまだ設計確定していない。Piの3.3Vから8台のセンサを直接給電する構成ではない。

旧アナログ用バッファ基板はToF方式では使用しません。旧Rev Cは変更しておらず、小型版に切り替えると現在のJLCPCB配置補正は流用できません。

## 基板接続の再番号付け

**J1はPiの40端子番号と一致しません。** `source/pi-wiring.csv`を必ず使います。
旧40穴から使用信号17点＋NC1穴の2×9直付けパッドへ縮小。重複GNDは1本に集約。
3.3Vの制御・I2C回路だけのGNDで、コイル電流を通しません。

| 本基板の位置 | 配線 |
|---|---|
| J1 | Pi直付け配線。1〜17番はpi-wiring.csv参照、18番NC |
| J3 | 1=GND、2/3=UP_OUT IN1/IN2、4/5=UP_IN IN1/IN2、6/7=LOW_OUT IN1/IN2、8/9=LOW_IN IN1/IN2、10番NC |
| J4 | 1=GND、2=Pi側3.3Vロジック、3=SDA、4=SCL。ToF切替基板のホスト側へ |
| TP1 | 1=GND、2=CLEAR_N、3=POWER_GOOD、4=UP_OUT_Q、5=UP_IN_Q、6=LOW_OUT_Q、7=LOW_IN_Q |

J4の2番はホスト側ロジック用。専用センサ電源の3.3V出力をPiの3.3Vへ並列接続しません。
I2C切替基板の電源順序・逆給電・ケーブル容量・通信速度は次工程です。

### 小型駆動基板との配線

| 制御IO MINI | DRIVE MINI |
|---|---|
| J3-1 GND | J2/J3/J4/J5の各1番へ分配 |
| J3-2 / J3-3 | 駆動J2の2番/3番 |
| J3-4 / J3-5 | 駆動J3の2番/3番 |
| J3-6 / J3-7 | 駆動J4の2番/3番 |
| J3-8 / J3-9 | 駆動J5の2番/3番 |

**基板ごとのJ1/J3は別物です。駆動基板J1は12V入力なので、制御基板J1へ接続しません。**

## 実装と機械条件

- 2層の配置案、M2用2.2mm穴4個。中心（2.5,2.5）、（47.5,2.5）、（2.5,37.5）、（47.5,37.5）mm。
- 旧100mm角・M3固定穴とは互換なし。
- 信号直付けパッドは2mmピッチ、穴0.8mm、ランド1.4mm。26〜28AWG程度を初期想定し、実際の電線外径・はんだ付け・引張り止めを確認。
- TP1は1.2mmの表面測定パッド。細いプローブで測定し、コネクタは付けない。
- 抵抗・コンデンサ等の記号はF.Fab中心。組立図と配線表で位置を照合。
- 部品モデル、吸着原点とJLCPCB回転は新しい基板で再確認。
